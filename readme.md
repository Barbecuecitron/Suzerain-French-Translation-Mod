## 🛠️ Installation

<details>
<summary>🆕 Première installation</summary>

### Étape 1 : Installation de MelonLoader

1. **Lancez** `MelonLoader.Installer.exe`

   > Si vous avez déjà une version de MelonLoader pour Suzerain, désinstallez-la d'abord

2. **Sélectionnez** Suzerain dans le menu MelonLoader
3. **Choisissez** la version **0.7.2**
4. **Cliquez** sur "Install"

<img src="media/readme/demo.gif" width="25%" alt="demo">

### Étape 2 : Installation du patch de traduction

1. **Lancez** `SuzerainTranslationInstaller.exe`

   > Un menu simple (mais efficace) s'ouvrira

2. **Vérifiez le chemin** vers Suzerain
   - Il devrait être détecté automatiquement
   - Sinon, localisez manuellement : `Steam\steamapps\common\Suzerain\Suzerain.exe`
3. **Cliquez** sur "INSTALLER"

**C'est terminé !** Lancez le jeu et profitez ! 🎮

</details>

<details>
<summary>🔄 Mise à jour</summary>

Pas besoin de réinstaller MelonLoader, il suffit de mettre à jour le patch :

1. **Téléchargez** la nouvelle version du mod (bouton vert **"Code"** → **"Download ZIP"**)
2. **Dézippez** le contenu dans un dossier de votre choix (vous pouvez supprimer l'ancienne copie, qui est désormais obsolète).
3. **Lancez** `SuzerainTranslationInstaller.exe`
4. Cliquez sur **"DÉSINSTALLER"** pour retirer l'ancienne version
5. Cliquez sur **"INSTALLER"** pour appliquer la nouvelle

**C'est tout, bon jeu !** 🎮

</details>
